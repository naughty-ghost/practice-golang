# 08 - マップ

## 問題

以下の処理を行うプログラムを作成してください。

1. 果物の在庫マップを作成する: `apple: 3`, `banana: 5`, `orange: 2`
2. すべてのキーと値を出力する
3. `grape: 8` を追加する
4. `banana` を削除する
5. `melon` が存在するかチェックし、結果を出力する
6. 最終的なマップを出力する

## 出力例

```
--- 在庫一覧 ---
apple: 3
banana: 5
orange: 2
grape を追加しました
banana を削除しました
melon は存在しません
--- 最終在庫 ---
apple: 3
orange: 2
grape: 8
```

※ マップの順序は実行ごとに異なる場合があります。

## 解説

### キーの存在チェック

マップから値を取り出すとき、2 番目の戻り値でキーの存在を確認できます。

```go
value, ok := m["key"]
if ok {
    // キーが存在する
}
```

存在しないキーにアクセスすると、値の型のゼロ値が返ります。
