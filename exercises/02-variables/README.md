# 02 - 変数と型

## 問題

以下の変数を宣言し、それぞれの値を出力してください。

1. `name` : 文字列型、値は `"Gopher"`
2. `age` : 整数型、値は `10`
3. `height` : 浮動小数点型、値は `1.75`
4. `isActive` : 真偽値型、値は `true`
5. `score` : 整数型、宣言のみ（ゼロ値を確認）

## 出力例

```
名前: Gopher
年齢: 10
身長: 1.75
有効: true
スコア: 0
```

## 解説

### 変数宣言の方法

Go には主に 3 つの変数宣言方法があります。

```go
// 1. var で型を明示
var name string = "Gopher"

// 2. var で型推論（右辺から型が決まる）
var age = 10

// 3. 短縮宣言（関数内のみ使用可能）
height := 1.75
```

### ゼロ値

Go では変数を宣言して初期値を与えない場合、型に応じた **ゼロ値** が自動的に設定されます。

| 型 | ゼロ値 |
|---|--------|
| int | `0` |
| float64 | `0` |
| string | `""` (空文字) |
| bool | `false` |
