# 11 - ポインタ

## 問題

以下の要件を満たすプログラムを作成してください。

1. `Double(n int)` 関数を作り、引数を 2 倍にしようとする（値渡し）
2. `DoublePtr(n *int)` 関数を作り、ポインタ経由で引数を 2 倍にする（参照渡し）
3. `main` で変数 `x := 10` を宣言し、それぞれの関数を呼んだ後の `x` の値を出力する

## 出力例

```
初期値: 10
Double後: 10
DoublePtr後: 20
```

## 解説

### ポインタとは

ポインタは変数のメモリアドレスを格納する変数です。

```go
x := 10
p := &x   // xのアドレスを取得
fmt.Println(*p)  // 10 （アドレスの先の値を参照）
*p = 20          // アドレスの先の値を変更
fmt.Println(x)   // 20
```

- `&` : アドレス演算子。変数のアドレスを取得する
- `*` : 間接参照演算子。ポインタの先の値を取得・変更する

### なぜポインタが必要か

Go の関数は引数を **値渡し**（コピー）します。関数内で引数を変更しても、呼び出し元には影響しません。
呼び出し元の変数を変更したい場合、ポインタを渡します。
