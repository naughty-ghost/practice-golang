# 07 - 配列とスライス

## 問題

以下の処理を順番に行うプログラムを作成してください。

1. 配列 `[3]int{10, 20, 30}` を宣言し出力する
2. 空のスライスを作り、`append` で `1, 2, 3, 4, 5` を追加して出力する
3. 上記スライスから 3 番目の要素（値 `3`）を削除して出力する
4. スライス `[1, 2, 3, 4, 5]` を逆順に並び替えて出力する

## 出力例

```
配列: [10 20 30]
スライス: [1 2 3 4 5]
削除後: [1 2 4 5]
逆順: [5 4 3 2 1]
```

## 解説

### 配列とスライスの違い

- **配列**: サイズ固定。`[3]int` と `[5]int` は別の型
- **スライス**: サイズ可変。内部的には配列への参照を持つ

### スライスの要素削除

Go にはスライスから要素を削除する組み込み関数がありません。`append` を使ったイディオムで削除します。

```go
// index番目の要素を削除
slice = append(slice[:index], slice[index+1:]...)
```
