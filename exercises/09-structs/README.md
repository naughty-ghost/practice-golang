# 09 - 構造体

## 問題

以下の要件を満たすプログラムを作成してください。

1. `Dog` 構造体を定義する（フィールド: `Name string`, `Age int`）
2. `Dog` にメソッド `Bark()` を定義し、`"ワン! 私は{Name}、{Age}歳です"` を出力する
3. `Dog` にメソッド `Birthday()` を定義し、`Age` を 1 増やす
4. `main` で `Dog` を作成し、`Bark()`、`Birthday()`、再度 `Bark()` を呼ぶ

## 出力例

```
ワン! 私はポチ、3歳です
誕生日を迎えました
ワン! 私はポチ、4歳です
```

## 解説

### 値レシーバとポインタレシーバ

- **値レシーバ** `func (d Dog)`: 構造体のコピーに対して操作する。元の値は変わらない
- **ポインタレシーバ** `func (d *Dog)`: 構造体そのものに対して操作する。フィールドを変更できる

フィールドを変更するメソッドにはポインタレシーバを使います。

```go
// 値レシーバ: 読み取りのみ
func (d Dog) Bark() { ... }

// ポインタレシーバ: フィールドを変更可能
func (d *Dog) Birthday() { d.Age++ }
```
